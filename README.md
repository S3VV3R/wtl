# Grand Theft Auto VI — Welcome to Leonida

Фанатский промосайт о мире GTA VI с фотореалистичными изображениями. Все виды города, персонажи и автомобили представлены изображениями WebP. Установка графического движка не требуется.

## Запуск

Распакуйте архив и откройте **Welcome-to-Leonida.html** в Chrome, Edge или Firefox. В этот файл встроены изображения, стили и код. Для просмотра трейлеров нужен интернет.

## Управление

- Кнопки на первом экране перелистывают панорамы Леониды.
- Нажмите на карточку региона, чтобы увидеть изображение целиком. В просмотрщике работают свайпы, стрелки и клавиша Escape.
- В разделе Vice City перемещайте ползунок, чтобы сравнить набережную на закате и ночью.
- В гараже стрелки переключают автомобили. Кнопки **Front view** и **Rear view** меняют ракурс. Кнопка увеличения открывает выбранный кадр в галерее.
- В верхнем меню можно выбрать размер изображений или включить звуки прибоя. Параметр **Original** показывает кадры в полном разрешении.

## Исходники и сборка

Проект использует React, TypeScript, Vite и GSAP. Нужен Node.js 22 или новее.

```sh
npm install
npm run dev
```

Для сборки выполните `npm run build`. Готовую папку `dist` можно разместить на статическом хостинге. Чтобы запустить включённую в архив сборку локально без установки пакетов, выполните `node tools/serve.cjs` и откройте адрес из консоли.

Команда `npm run build:portable` собирает проект с помощью Webpack. Для отдельного HTML-файла выполните `node tools/make-standalone.cjs Welcome-to-Leonida.html`.
